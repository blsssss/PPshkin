# Письмо о намерениях участвовать в пилоте

Шаблон. Письмо не является договором и не создаёт обязательств. Со стороны проекта оно не подписывается до регистрации юрлица или ИП; договор или оферта появятся после #92. План работы с заведениями: [pilot-partners.md](pilot-partners.md).

---

Мы, заведение, указанное ниже, намерены участвовать в пилоте сервиса горящих позиций в Казани.

**1. Срок пилота.** С `<дата начала>` по `<дата окончания>`. Даты ориентировочные, их можно уточнить по согласованию сторон.

**2. Стоимость.** Участие в пилоте бесплатно. Условия после пилота обсуждаются отдельно по его результатам.

**3. Что делает заведение.** В общих словах: выставляет остатки в боте как горящие позиции, закрывает день, гасит брони по QR, делится обратной связью раз в неделю.

**4. Что делает проект.** В общих словах: обеспечивает работу сервиса, помогает с подключением, показывает отчёт «выставлено / продано / списано», отвечает на вопросы.

**5. Данные.** Заведение видит только агрегированную статистику и данные броней без данных гостя: код, блюдо, цену, время и статус брони.

**6. Выход.** Любая сторона может выйти из пилота в любой момент, сообщив об этом другой стороне.

**7. Характер письма.** Письмо выражает намерение и не обязывает ни одну из сторон.
